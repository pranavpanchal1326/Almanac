# ADR 0004: Gate 2 — the model beats the reference on the backtest but misses the margin

Date: 2026-11-21        Status: **proposed**; the decision is the project owner's

Blueprint 16.4 names this record "decision record 0002"; ADR numbers 0002 and 0003 were already
used (regional start, Gate 1), so it is 0004. The gate's scheduled date is 27 December 2026; it
is prepared early because every input it needs now exists. The lock is 15 January 2027.

## Context

Phase 2 asks: does a learned model beat the best simple method on places and years it has not
seen? The rules are the pre-registration (`docs/prereg/2027.01.md`), amendment 1 (the model and
the graded forecast) and amendment 2 (the stable recipe, the reference, and no amendment 3).

### A deviation to disclose

Amendment 1, section 8 forbids "any run that reads the 2025 test truth other than the single
stage B evaluation". The task 2.8 reproduction (2026-11-21 15:42 UTC, logged) read the 2025 test
truth a second time. It was planned as blueprint task 2.8, but the amendment's text does not
except it, and this was not noticed before the run. What limits the harm:

- it scored the same frozen package, whose digest was checked before any truth was read, so no
  forecast, weight or setting could change;
- it produced the same numbers as stage B (largest difference 4.3e-16), so nothing was learned
  that stage B had not already reported;
- it is logged, and it is disclosed here and in `docs/phase2/STATUS.md`.

It cannot be undone. The record should state it plainly, and no further run may read the 2025
test truth for issue 2027.01, including the second person's re-grade of task 2.8; that re-grade
can instead rebuild the package from the frozen weights and compare digests, which reads no
truth.

## The question

The outcome table in blueprint 16.4 does not cover this case exactly:

| Outcome | Condition | Applies? |
|---|---|---|
| Pass | Win condition met on stage B | No: condition 1 fails |
| Partial | Model beats B0–B3 but not B4, or the interval's lower end is below 10% | Not literally: the model beats B4 and the reference, and the lower end is 10.7% |
| Fail | Model does not beat B3 | No |

The table was written when B4 was the reference. Amendment 2, section 5 adds: "If the A2 runs are
also unstable or do not beat the reference, the result is reported as it is, and the plan's
fallback applies: the forecast of the best baseline is locked on 15 January 2027." The A2 runs
are stable. Whether they "beat the reference" depends on what "beat" means:

- **Reading 1, "beat" means the win condition.** The model does not beat the reference, and the
  best baseline's forecast is locked as issue 2027.01. The best baseline on validation, by
  amendment 2's own rule, is B5 (A2), not B4 as `docs/phase4/STATUS.md` still says.
- **Reading 2, "beat" means a better score.** The model beats the reference on every part, with
  the whole interval above +10%, so the fallback does not apply. With the win condition unmet, the
  nearest row is Partial: "lock the forecast anyway, labelled honestly".

Neither reading changes the exam's win condition: issue 2027.01 is graded on 2026 truth against
the reference with the same three conditions, whichever forecast is the headline, and all
forecasts (model, reference, B0–B4) are locked in the same package either way (blueprint 12,
"baselines are locked with the forecast").

## Options

| | A. Lock the model as the headline forecast (Reading 2) | B. Lock the best baseline as the headline (Reading 1) |
|---|---|---|
| Headline of issue 2027.01 | Model M (A2), labelled: backtest +16.0% over the reference, below the pre-registered 20% margin; win not met | B5 (A2), with the model locked beside it as a secondary forecast |
| What the exam tests | Whether the model clears the 20% margin on 2026 | The same comparison, but the public claim is the baseline's |
| Risk | Read as moving the goalposts after seeing the test, unless the label is plain | Locks the weaker forecast on every part of the backtest |
| Fits | Section 5's plain words; the Partial row's action; blueprint 16.4, "the exam is worth taking either way" | The strict spirit of a pre-registration: anything short of the win is the fallback |

## Recommendation (for the owner to accept or reject)

**Option A, with the label written before the lock and nothing else changed.** Reasons:

1. Section 5 says "do not beat the reference", not "do not meet the win condition"; the
   pre-registration uses "win condition" where it means the three conditions, and the model
   beats the reference on all exam tiles, on test tiles and on the held-out region, with the whole
   95% interval above +10%.
2. Option B would lock, as the headline, a forecast that scored lower on every part of the only
   test it has had. That does not protect the record; it hides the better forecast.
3. The pre-registered claim is not weakened. The exam still needs 20%, and the public label says
   in its first line that the backtest fell short of it.

What should not change under either option: the frozen weights, the calibration maps, the
reference, the win condition, and the "no refit" rule (amendment 1, section 7).

## The opposite case, argued

**"Anything short of the win must trigger the fallback; reading 2 is a loophole."** It is the
strongest objection. A pre-registration is worth something only if its words are not stretched
after the result is known, and this question is being settled after the result is known. Two
things answer it in part: the reading is about which forecast is the headline, not about whether
the model won (the record says it did not), and the comparison graded in 2027 is unchanged. If
the owner reads section 5 strictly, Option B is consistent and nothing is lost scientifically,
because the model is locked beside the baseline and graded anyway.

**"The 2025 result flatters the model; validation said the opposite."** On validation 2024 the
model was 4.6% below the reference. Validation has 146 tiles in one year; its interval ran from
−12.6% to +11.0%, so it could not tell the two apart. The reference was also picked as the best of
six candidates on that same validation set, which favours it there. Stage B is the larger test
(499 tiles, two parts, both positive), but it is one year.

**"Ablations were not run, so we do not know why the model is better."** True. The blueprint's
schedule guard permits cutting ablations to the neighbours comparison, and M against B5 under the
same recipe is that comparison; but B5 has one seed, so its size is uncertain. Ablations are
validation only and cannot change the forecast (amendment 1, section 8), so they can still be run
before the lock for the record.

**"The probabilities are poorly calibrated."** True out of sample (ECE 0.0288 on 2025). The
primary metric, AP, depends only on ranking. The calibration maps are fixed by amendment 1 and may
not be refitted on 2025; the published forecast must say that its probabilities run high or low by
up to a few points in the upper bins, with the 2025 reliability table attached.
